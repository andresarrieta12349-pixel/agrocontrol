🌾 AgroControl Pro

Sistema Integral de Gestión Agrícola - Frontend Profesional

📋 Descripción del Proyecto

Frontend moderno y profesional para AgroControl Pro, desarrollado con HTML5, CSS3 y JavaScript vanilla (sin dependencias externas). Diseño corporativo pensado para computadores de escritorio con máximo ancho de 1280px.

✅ Autenticación

Login seguro con JWT

✅ Responsive

Optimizado para desktop

✅ CRUD Completo

Create, Read, Update, Delete

✅ Validación

Datos verificados

📄 Páginas Principales

🔐 Login

Pantalla de autenticación moderna y profesional con validación en tiempo real.

index.html

📊 Dashboard

Panel principal con estadísticas, acciones rápidas y actividad reciente.

pages/dashboard.html

📦 Insumos

Gestión completa de insumos agrícolas (fertilizantes, pesticidas, etc.).

pages/inputs.html

🐄 Ganado

Administración de animales con seguimiento de salud y valuación.

pages/livestock.html

🚜 Maquinaria

Control de equipos agrícolas con estado y seguimiento de revisiones.

pages/machinery.html

📁 Estructura de Directorios

Estilos CSS (frontend/css/)
  • main.css - Estilos globales y variables CSS
  • login.css - Estilos de autenticación
  • dashboard.css - Dashboard y sidebar
  • modules.css - Formularios y tablas
Scripts JavaScript (frontend/js/)
  • auth.js - Gestión de autenticación
  • sidebar.js - Navegación lateral
  • dashboard.js - Lógica del dashboard
  • inputs.js - CRUD de insumos
  • livestock.js - CRUD de ganado
  • machinery.js - CRUD de maquinaria
Utilidades (frontend/utils/)
  • api.js - Cliente HTTP centralizado
  • validation.js - Validadores personalizados
  • utilities.js - Funciones de utilidad
